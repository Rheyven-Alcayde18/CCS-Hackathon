# LSPU-SPCC Hackathon Event Registration System

Prototype modular website for the Bundled-Service/Modularity Design Activity.

## Included
- Home / landing page
- Login
- Participant registration
- Student dashboard
- Event schedule
- Reservation/slot booking
- Admin dashboard prototype
- Responsive UI
- LocalStorage demo persistence

## Technology mapping
- HTML / CSS / JavaScript — frontend
- Node.js — prototype server
- Bootstrap — proposed reusable Library
- Firebase Authentication SDK — proposed SDK-based Service
- FullCalendar — proposed Plug-in/Extension
- Google Calendar API — proposed API Service
- Firebase Firestore — proposed Cloud Service

## Run
Open `index.html` directly, or install Node.js and run:
`node server/server.js`
Then open `http://localhost:3000`.

This is a front-end prototype; external Firebase/Google integrations are represented architecturally and are not connected to real credentials.
